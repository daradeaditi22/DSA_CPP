# DSA_CPP 
# 📚 DSA in C++

A collection of **Data Structures and Algorithms** programs implemented in **C++**, written while learning and practicing core DSA concepts. Each program is a single, self-contained file that you can compile and run on its own.

## ▶️ How to Run

**1. Clone the repository**
```bash
git clone https://github.com/daradeaditi22/DSA_CPP.git
cd DSA_CPP
```

**2. Compile a program**
```bash
g++ bubblesort.cpp -o bubblesort
```

**3. Run it**
```bash
./bubblesort          # Linux / macOS
bubblesort.exe        # Windows
```

> 💡 Replace `bubblesort` with any file name from the table above.
